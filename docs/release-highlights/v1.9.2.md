**A maintenance release — no new features, but several things that were quietly
going wrong are now fixed.** This covers both **1.9.2** and **1.9.1**, since 1.9.1
went out without a summary and most people will update straight from 1.9.0.

Two of these are worth two minutes of your time, because they may affect work you
have already done.

### 🔎 Some documents could be skipped without the app saying so — Mac only

If a file's extension was in **capitals** — `REPORT.PDF` rather than `report.pdf`,
which is how many school photocopiers and scanners name what they produce — the Mac
version didn't see it when you pointed at a **folder**.

A folder where *everything* was in capitals at least said "No files available for
processing", which is hard to miss. A **mixed** folder was the real problem: it
processed the lower-case files, and said nothing at all about the rest.

> **Worth a look:** if you have redacted a folder on a Mac that contained anything
> scanned, compare how many files are in your `redacted` folder against the folder you
> started from. If it's short, the missing ones are the capitalised names — just run
> that folder again on this version.

Choosing a **single document** was never affected, and **Windows** was never affected.

### 🔒 Word documents left an unredacted copy beside your originals

To read a Word document, the app first converts it to a PDF. That converted copy — a
complete, **un**redacted copy of the document — was being written into a hidden folder
called `.temp_converted` next to your originals, and nothing ever deleted it.

That mattered more than it sounds. The folder is hidden on a Mac but **fully visible on
Windows**, and school folders usually sit inside OneDrive — so those copies were being
synced to the cloud by an app whose whole promise is that nothing leaves your computer.
If you ever dragged the folder into an AI tool, they went along too.

Conversions now happen in your computer's temporary area instead, well away from your
documents, and are cleared as it goes. **If an old `.temp_converted` folder is still
sitting next to your documents, this version deletes it the next time you process that
folder.**

### 🐛 Also fixed

- **"Report this problem" could include a student's name.** The email strips file paths
  before you send it, but it stopped at the first space — and with names like
  `Billy Bob Support Report.pdf`, the surname was on the wrong side of that space. It
  now removes the whole path.
- **A document that failed its final safety check could keep a name saying it was
  redacted** (Windows). Anything that fails verification is now always set aside as
  `.UNVERIFIED`, so it can never be mistaken for a finished file.
- **Two documents could end up sharing one quarantine file.** If two files in a run had
  similar enough names and both failed the safety check, the second quietly wrote over
  the first — so you were told two files needed checking but only given one. Both are
  now kept.
- **A big folder of Word documents could report "the redaction engine isn't
  responding"** when it was working perfectly well, just taking its time. Restarting at
  that point lost the run. It now waits as long as the job needs.
- **A black command window no longer appears beside the app** on Windows.
- **Starting over now clears the app's memory of the run**, so the last student's text
  isn't held on to while the app stays open.

*Nothing about how you use the app has changed — same screens, same steps, same output.*
