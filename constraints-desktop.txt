# Exact versions for the packaged app's bundled Python.
#
# requirements-desktop.txt only sets minimums, so without this file every
# release build installs whatever is newest on PyPI that day. By October 2026
# that meant PyMuPDF 2.0, Pillow 13 and Starlette 1.x: majors that would have
# shipped to every user through the auto-updater without a single test run.
# (Pillow 13 and Starlette 1.x were later adopted on purpose, with a test run.)
#
# FastAPI is held at 0.141.1: from 0.142.0 it requires opentelemetry-api, and
# 0.143-0.162 were a run of breaking releases. 0.141.1 with Starlette 1.3.1 is
# a pair FastAPI's own test suite ran.
#
# Both bundle scripts install with `-c constraints-desktop.txt`. A pin only
# applies to a package the platform actually installs (uvloop on Mac, colorama
# on Windows), so one file serves both.
#
# To move a version: change it here, install the same set into venv/, run the
# full pytest suite, then do a packaged --dir build and launch it.
# The spaCy model (en_core_web_lg) is not listed: `spacy download` picks the
# model that matches the pinned spaCy.
